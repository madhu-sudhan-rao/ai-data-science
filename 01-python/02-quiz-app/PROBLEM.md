Imagine a simple technical quiz for developers.

3. Your development challenges
We'll build this in three versions.

Version 1 — Basic Quiz
- Create at least 5 multiple-choice questions.
- Each question should have 4 options: A, B, C, D.
- Accept the user's answer.
- Check whether the answer is correct.
- Maintain the correct answer count.
- Display the final score and percentage.


Version 2 — Input Validation
- Accept lowercase and uppercase answers.
- Reject invalid options such as E or X.
- Keep asking until the user enters a valid option.
- Allow the user to skip a question.


Version 3 — Quiz Experience
- Ask whether the user wants to play again.
- Display correct and incorrect answers.
- Track skipped questions.
- Display a final performance summary.

4. Your first task
Start with Version 1 only.

A few guidelines:
1. Use only core Python. No external libraries.
2. You can use lists and dictionaries if you want to organize questions and answers.
3. Don't worry about making the code perfect.
4. Don't use functions or classes yet. We'll cover those in later projects.
One important thing: Decide how you want to store your questions and their answers. That's part of the learning exercise.
